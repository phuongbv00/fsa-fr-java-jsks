# FSA Java Web — training material

Public teaching material for the `HN_FR_JSKS_JAVA_WEB` programme.
Built with [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) and
published to GitHub Pages on every push to `main`.

## This repo is generated

`docs/` and `mkdocs.yml` are **written by tooling in the private source repo** and
committed here. Editing them by hand works until the next sync, which overwrites
them. Edit the source material instead, then re-run the sync.

Only allowlisted, learner-facing content is ever written here. Instructor
material — grading rubrics, quiz answer keys, and exam briefs — is withheld at
the source and never enters this repository or its history.

## Local preview

```bash
pip install -r requirements.txt
mkdocs serve
```
